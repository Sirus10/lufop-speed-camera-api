Lufop Speed Camera API

The Lufop API helps developers integrate speed camera and road hazard data into GPS, navigation, mapping and mobility applications.

Retrieve data by country, city or GPS coordinates. Responses are available in JSON and XML, with compact JSONC and advanced synchronization features available on Pro and Business plans.

Coverage and data detail vary by country. The Free plan covers France, Belgium and Switzerland; Pro and Business plans provide access to additional countries, higher request limits and advanced features.

Lufop data is published under the Open Database License (ODbL) 1.0. API subscriptions cover the technical service, including quotas, API features and server resources; they do not grant exclusive rights to the data.
